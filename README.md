# NITCbase

> 🗄️ An educational **Relational Database Management System (RDBMS)** built to demonstrate the internal architecture of modern database systems.
>
> 🎓 Developed as part of the **Database System Design Laboratory** course at **NIT Calicut**.

## 📖 Overview

**NITCbase** is an educational Relational Database Management System (RDBMS) built from the ground up to help students understand how relational database systems work. Instead of treating a database as a black box, it exposes the core storage, indexing, and query-processing mechanisms through a modular **8-layer architecture**.

The implementation supports essential relational database functionality, including table management, record manipulation, SQL query execution, and **B+ tree** indexing.

---

## ✨ Features

### 🗃️ Database Operations

* ➕ Create, alter, and drop tables
* 📝 Insert records
* 🔍 Execute SQL queries
* 📌 Project selected attributes
* 🔗 Perform equi-joins
* 🌳 Create and manage indexes

### 💻 Supported SQL

```sql
CREATE TABLE
DROP TABLE
ALTER TABLE
INSERT
SELECT
PROJECT
EQUI-JOIN
CREATE INDEX
DROP INDEX
```

### 🌲 B+ Tree Indexing

* ⚡ Efficient B+ tree implementation
* 🚀 Faster record lookup
* 🛠️ Index creation and deletion
* 📈 Improved query performance

### 🏗️ Architecture

* 🧩 Modular eight-layer design
* 🧱 Object-oriented implementation
* 🔄 Separation of storage, indexing, query processing, and system management
* 🎯 Designed for learning database internals
